# Lumen Stellar — GitHub Pages

Esta pasta já está pronta para ser publicada diretamente no GitHub Pages.

## Publicação

1. Crie um repositório no GitHub, por exemplo `lumen-stellar`.
2. Envie **todo o conteúdo desta pasta para a raiz do repositório**.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.

A URL normalmente ficará no formato:

`https://SEU-USUARIO.github.io/lumen-stellar/`

## Observações

- O site é totalmente estático; Node.js não é necessário no GitHub Pages.
- O arquivo `.nojekyll` já foi incluído.
- Os caminhos usados pelo projeto são relativos, compatíveis com publicação em subpasta do GitHub Pages.
